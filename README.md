# Pause e Responda

Sistema educacional de quizzes para prática e reforço das aprendizagens.

## Proposta
O estudante seleciona nome, série, turma e disciplina e responde a questões precedidas por um texto curto de apoio.

## Disciplinas
- Carreira e Competências para o Mercado de Trabalho em Administração
- Introdução a Administração, Legislação e Pessoas
